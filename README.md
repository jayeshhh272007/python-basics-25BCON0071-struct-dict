# Struct-to-Dict in Python

## Overview
This project demonstrates how to convert a Python object's attributes into a dictionary.

## How It Works
- Defines a `Student` class.
- Initializes a student with a name, age, and course.
- Uses the `__dict__` attribute to access the object's attributes as a dictionary.
- Prints the resulting dictionary.

## How to Run
Run `struct-to-dict.py` using Python.

## Example Output
```python
{'name': 'Jayesh', 'age': 19, 'course': 'BTech CSE'}
```

## Learning Objective
To understand Python classes, objects, attributes, and dictionaries.
